# Dutcheyy Hard Rave Techno Serum 2 Blueprint

Build specification for a 12-patch Serum 2 sound-design pack.

- **Version:** 1.0
- **Tempo:** 152 BPM
- **Key:** G minor

The patch settings are provided in [`blueprint.json`](blueprint.json). They are precise Serum 2 build specifications, not binary `.SerumPreset` files. Enter each patch's settings in Serum 2 and save the patch from the instrument.
